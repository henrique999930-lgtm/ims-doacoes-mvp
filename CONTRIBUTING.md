# Fluxo de contribuição acadêmico

1. Crie uma branch a partir de `main`: `git switch -c feat/nome-da-mudanca`.
2. Faça alterações pequenas e coerentes.
3. Execute `python manage.py test`.
4. Faça commit com mensagem objetiva, por exemplo: `feat: melhorar validação de entrega`.
5. Envie a branch e abra um Pull Request para `main`.
6. Aguarde o CI ficar verde antes do merge.

Mesmo sendo um projeto individual, o Pull Request funciona como registro de auto-revisão técnica.
