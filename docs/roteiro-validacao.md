# Roteiro de validação do protótipo

Use somente com participante que tenha concordado com o teste e apenas com dados fictícios.

## Tarefa 1 — Localizar família
Localizar `Maria Exemplo` e iniciar uma nova entrega.

## Tarefa 2 — Registrar entrega
Registrar 2 unidades de Arroz e 2 unidades de Feijão.

## Tarefa 3 — Interpretar resultado
Confirmar a conclusão e identificar os saldos atualizados.

## Critérios
- sucesso: 3 de 3 tarefas;
- tarefa central: até 120 segundos;
- satisfação: nota mínima 4/5 para facilidade de uso.
